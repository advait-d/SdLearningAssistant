You are an evaluator assessing the quality and accuracy of an AI-generated system design response.

Given the user request, supplementary context (may be empty), and the AI's response, calculate a confidence score.

IMPORTANT SCORING RULES:
- If the AI says "I don't have enough information" or refuses to answer a standard system design question, this is a POOR response. Score it 0.1 to 0.3.
- If the AI provides a substantive, accurate, well-structured system design answer, this is a GOOD response even if the context section was empty — the AI has inherent expertise.
- Only penalize the AI for actual factual errors or incoherent answers, NOT for answering without context.

Input:
User Request: {user_request}
Supplementary Context: {context}
AI Response: {ai_response}

Scoring criteria:
- 0.9 - 1.0: Substantive, expert-level response that correctly addresses the user's question with depth and accuracy.
- 0.7 - 0.8: Mostly accurate response, covers the main points but could be more detailed.
- 0.4 - 0.6: Partial answer, vague, or missing key concepts the user was asking about.
- 0.0 - 0.3: The AI refused to answer, said it lacked information for a well-known topic, gave factually wrong information, or completely failed to address the question.

Output Format:
You must return only a valid JSON object. Do not include any markdown or code fences.
{{
  "score": <float>,
  "reason": "<one-sentence justification>"
}}
